# Exercise illustrations

Drop one PNG per exercise here, named by slug: `exercises/<slug>.png`.

The app builds the slug from the exercise name (lowercase, non-alphanumeric → `-`):
- `KB Floor Press` → `kb-floor-press.png`
- `ATG Split Squat` → `atg-split-squat.png`
- `Banded Overhead Pull → Straight-Arm Pulldown` → `banded-overhead-pull-straight-arm-pulldown.png`

Canvas 1600×560, solid `#F4F3EE` background, no transparency. See `exercise-art-prompts.md` in the project root for the ChatGPT brief per exercise.

The `ℹ` tooltip shows the image automatically once the file exists; missing images are hidden gracefully.
